# Tests Disclosure

The AI-generated tests in this folder were written to help AI coding tools verify behaviour during development. They capture the expectations inferred from the instructions and implementation available at the time, and may not fully reflect what the author actually expects.

A passing test only confirms the behaviour that it checks. Review those expectations with the author before treating them as requirements. If a test disagrees with the intended behaviour, correct the expectation and implementation as appropriate.

Tests should follow realistic paths that reflects the actual usage. They should not be overly strict or overly lenient just to merely satisfy asserted tests while completely missing the intended behaviour. As per Goodhart's law, "When a measure becomes a target, it ceases to be a good measure.".
